# YatSenOS 实验记录

实验结构如下：

实验零：实验准备

实验一：操作系统的启动

实验二：中断处理

实验三：内核线程与缺页异常

实验四：用户程序与系统调用

实验五：fork、阻塞与并发

实验六：硬盘驱动与文件系统

实验七：更好的内存管理

实验八：扩展实验

其中，实验零的主要任务是搭建实验环境、了解工具和 Rust 语言，而其他实验是一个逐步完善的操作系统整体代码，因此，我把实验零单独放在一个 lab0 文件夹，其余实验放在 yyos 文件夹中。

git 仓库的逻辑是：每完成一个实验，就在这个实验的基础上新建一个分支，这样可以继承之前的实验代码继续构建操作系统，也可以通过切换分支随时回退到任一个实验的状态。

final 为最终实验应该提交的部分，对比 lab8 分支没有新增内容，只是删去了之前实验所写的实验报告以及 typst 源码文件，删去了官方实验文档的代码参考、实验报告的模板文件夹、实验报告所需的截图以及运行输出的结果文件，只保留 lab0 、yyos 两个实验代码文件和实验报告以及提供测试的python文件。

关于操作系统命名：原实验操作系统名字为 YatSenOS，在本实验的前几个实验中一直沿用这个名字，但是到某个实验开始我把这个名字改成了yyos，用我的名字来命名这个操作系统，相应把配置文件中所有有关名字都从 ysos 改成了 yyos，实验启动的时候也是展示 yyos 这个名字。
